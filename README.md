# 115 學年度各處室業務 Q&A｜新北市立鶯歌工商

將輔導室彙整的《115 本校各處室業務 Q&A》（115.9）轉製為可互動瀏覽的單頁網站。

## 內容範圍

- **89 則問答**，涵蓋 14 個處室／科別單位
  教務處、學務處、教官室、總務處、實習處（陶工、美工、廣設、多媒、資訊、資處、應日）、輔導室、圖書館、進修部
- **費用與收費標準專區**：附件一（學費、雜費、代收代付費）、附件二（代辦費）、附件三（新生制服估價單）、電費統計表
- **升學查詢常用連結** 7 則

## 功能

### AI 智慧問答（首頁）
以日常口語提問即可，不必先知道是哪個處室負責。

- 概念詞庫擴展：把「坐車」「沒錢」「被當」等口語對應到文件裡的正式用語
- 處室／科別辨識與身分加權（家長／新生／在校生／進修部）
- 字元二元組 TF-IDF 排序，檢索範圍 102 則（89 則問答 ＋ 13 則費用條目）
- 輸入即時建議、答案卡（偵測主題、承辦處室、相符程度）、相關問答、一鍵跳至原文

> **注意：**本引擎完全在瀏覽器端執行，**未串接任何外部 AI 服務、不需 API 金鑰**。
> 這是刻意的設計：靜態網頁若內嵌 API 金鑰，任何人檢視原始碼即可取得。
> 引擎只會回傳文件中真實存在的內容，不會生成臆測的答案。

### 其他
- 關鍵字全文篩選、單位標籤、★ 收藏（localStorage）
- 手風琴展開／收合、捲動進度條、導覽列高亮
- 列印／存 PDF（列印前自動展開全部問答）
- RWD：桌機與手機皆無水平溢位

## 技術

單一 `index.html`，無建置步驟、無相依套件。
外部資源僅 Google Fonts（Noto Serif TC／Noto Sans TC）。

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可。

## 部署

靜態網站，Vercel 匯入此 repo 後不需任何設定：

- Framework Preset：**Other**
- Build Command：留空
- Output Directory：留空（根目錄）

`vercel.json` 僅設定 `cleanUrls` 與兩個安全性標頭。

## 資料正確性

各項收費標準、招生與檢定時程、交通車路線及班次，
**均以學校官網最新公告與教育局來文為準**。本頁內容僅供親師生參考。
